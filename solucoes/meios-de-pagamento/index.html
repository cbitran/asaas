Caso você receba um chargeback, mas não concorda com essa solicitação, é possível contestá-lo. Veja como contestar chargebacks dentro do Asaas.

Para antecipar recebíveis, alguns requisitos devem ser seguidos e ela está disponível para algumas opções de pagamento: Antecipar boletos: basta ter cadastro aprovado e cobranças com vencimento superior a 8 dias úteis. Para Pessoa Jurídica, antes de solicitar a antecipação é necessário aguardar 45 dias após a primeira transferência (TED ou Pix) da conta Asaas para uma conta bancária externa. Para Pessoa Física, o prazo de liberação do produto é de 90 dias após a primeira transferência. Veja todos os requisitos para antecipação de boletos.
