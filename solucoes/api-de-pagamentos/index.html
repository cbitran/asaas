Uma API de pagamento é uma interface de programação de aplicações que possibilita integrar funcionalidades de pagamento, cobrança e recebimentos de forma automatizada e segura. Se tratando da API de pagamento do Asaas, ela permite que você utilize nossas soluções dentro do seu site, plataforma ou aplicativo, automatizando os seus processos de pagamento.

A API do Asaas é desenvolvida no padrão REST, ou seja, ela é compatível com qualquer linguagem de programação. Porém, não é possível desenvolver integrações usando scripts ou HTML, por exemplo. A conexão com as nossas APIs deve ser executada sempre pelo back-end da aplicação e nunca pelo front-end. Assim, mantemos o ambiente seguro.

A autenticação é realizada por meio de uma chave de API (API key). Por motivos de segurança, essa chave só pode ser gerada diretamente na interface web do Asaas e pelo próprio usuário. Importante: a chave de API será exibida apenas no momento da sua geração. Portanto, lembre-se de armazená-la com segurança em seu cofre de chaves, pois não será possível visualizá-la novamente depois.

Além do uso de sistemas antifraude, o Asaas segue os padrões de segurança PCI-DSS, um conjunto de normas e regras que gateways de pagamento, emissores de cartão ou qualquer agente que faça processamento, transmissão ou armazenamento de dados de cartão de crédito ou débito devem respeitar para garantir a proteção destes dados.

Podem ser processados pagamentos via Pix, boleto e cartão de crédito, sejam eles na modalidade recorrente ou parcelamento.

Um gateway de pagamento permite às empresas processar transações online de maneira segura, atuando como um intermediário entre o cliente, o comerciante e as instituições financeiras envolvidas. Sua principal função é facilitar a transferência segura de dados sensíveis, visando a autorização rápida do pagamento.
