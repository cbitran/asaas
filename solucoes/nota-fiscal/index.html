O Asaas é uma conta digital para empresas que oferece a emissão de Notas Fiscais de Serviço, diretamente pela plataforma, permitindo a automatização desse fluxo que é tão burocrático pelo portal da prefeitura.

O emissor de nota fiscal do Asaas já conta com mais de 2.000 prefeituras integradas, com uma média de 13 novas integrações por mês.

Segundo a Constituição, cada prefeitura é responsável por regulamentar a emissão, fiscalização e parametrização das Notas Fiscais de Serviço. Com isso, não há padronização a nível nacional, cada prefeitura tem sua normativa. Por isso, para emitir pelo Asaas, primeiramente é necessário possuir um cadastro ativo no portal da sua prefeitura. Nos casos de MEI, ter um cadastro ativo no Portal Nacional.

Não. Para emitir nota fiscal de serviço automaticamente pelo Asaas, é necessário realizar um cadastro como Pessoa Jurídica.

Para usar o emissor de nota fiscal automática, é necessário: possuir Inscrição Municipal regular; estar homologado na prefeitura para emissão de NFS-e via webservice (exceto MEI); possuir o modelo de autenticação exigido pela prefeitura, com usuário e senha, certificado digital ou token (exceto MEI); algumas prefeituras podem solicitar uma autorização para utilizar um intermediador para geração de NFS-e; realizar o cadastro completo do pagador.

Pelo emissor do Asaas, é possível emitir notas fiscais integradas ao Portal Nacional de NFS-e, que atualmente é obrigatório para contribuintes MEI e todos os portes de empresas. Nossas integrações acontecem por integração via API Rest, tendo uma integração específica para cada prefeitura que atendemos, garantindo que todos os protocolos e envios sejam realizados conforme a legislação vigente em cada município.

No Asaas, é possível emitir Notas Fiscais de Serviço (NFS-e), atreladas ou não a uma cobrança, possibilitando a emissão de nota fiscal avulsa. Além disso, o Asaas oferece integração com o ERP Base by Asaas, que possibilita a emissão de nota fiscal de produto, NF-e. Conheça o Base by Asaas!

Em seguida, basta configurar os dados através da aba “Notas Fiscais” no sistema e iniciar a emissão do documento.
